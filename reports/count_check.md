# 건수 검증표

- 데이터: 샘플 데이터 (data/sample)
- 파일: boxoffice_20261108_20261114.csv
- 기간: 2026-11-08 ~ 2026-11-14 (7일)
- 행 하나 = 영화 1편 × 날짜 1일 (키: date + movie_cd)
- 이 파일은 `python clean.py`를 실행할 때마다 자동으로 다시 만들어집니다.

## ① 박스오피스 정리 : 원본 − 제거 = 정리 후

| 단계 | 건수 | 설명 |
| --- | ---: | --- |
| 원본 | 70 | 수집 파일 전체 행 수 |
| 제거: 완전히 같은 중복 | -0 | 같은 날짜를 두 번 수집한 경우 |
| 제거: 키 중복 (값이 다름) | -0 | 같은 날짜·영화인데 값이 다른 행. 마지막 수집 값만 남김 |
| 제거: 필수값 빈칸 | -0 | date, movie_cd, audi_cnt 중 하나라도 빈 행 |
| **정리 후** | **70** | |

- 기대 행 수: 7일 × 10편 = 70행 → 실제 70행
- 하루 10편이 아닌 날: 없음
- 기간 중 빠진 날짜: 없음

## ② 영화 상세정보 결합 (영화코드 기준) : 전체 = 성공 + 실패

- ⚠️ 상세정보 파일(movie_info*.csv)이 아직 없어 결합하지 않았습니다. 장르·국가는 "정보없음".

## ③ 공휴일 결합 (날짜 기준)

- ⚠️ 공휴일 파일(holidays*.csv)이 아직 없어 모든 날을 공휴일이 아닌 날로 처리했습니다.

## ④ 상영 1회당 관객 수 계산

- 계산한 행: 70 / 계산 못 한 행(상영 횟수 0 또는 빈칸): 0
- 계산식: audi_per_show = audi_cnt ÷ show_cnt (소수 첫째 자리 반올림)

## ⑤ 제거·실패 건수 (0건이면 확인한 방법)

- 완전 중복: 0건 — 확인 방법: `duplicated()` 결과가 모두 False
- 키 중복: 0건 — 확인 방법: `duplicated(subset=[date, movie_cd])` 결과가 모두 False
- 필수값 빈칸: 0건 — 확인 방법: 필수 컬럼의 `isna().sum()`이 모두 0
