- **사용한 AI**: Claude
- **프롬프트**: collect.py 내용에 맞춰서 clean.py를 만드는 것을 도와달라고 요청. 이어서 팀이 정한 목적 문장("정리·결합: 중복·결측 처리, 날짜·영화코드로 결합, 상영 1회당 관객 수 계산")을 주고 이 목적에 맞게 만든 것인지 질문. 팀 .gitignore 내용을 붙여 넣어 저장 위치를 확인. 마지막으로 발표 때 설명할 수 있게 코드 설명을 요청
- **AI가 준 결과 요약**: src/clean.py와 tests/test_clean.py. collect.py 형식(movie_cd 같은 컬럼 이름, 2026-11-01 날짜 형식, boxoffice_시작일_종료일.csv 파일 이름)에 맞춰 여러 파일을 읽어 합친 뒤, 완전 중복과 키(date+movie_cd) 중복을 따로 세서 제거하고, 날짜·영화코드·관객 수가 빈 행을 제거함. 상세정보는 영화코드로, 공휴일은 날짜로 left join하고(아직 파일이 없으면 건너뜀), 결합 전후 행 수가 같은지 assert로 확인. 건수 검증표(reports/count_check.md)를 자동으로 만들고, data/raw가 비어 있으면 data/sample로 실행됨
- **직접 확인하거나 고친 점**: 팀 목적 문장과 대조해 상영 1회당 관객 수 계산이 빠진 것을 발견 → audi_per_show(관객 수 ÷ 상영 횟수, 상영 0회면 계산하지 않음) 추가와 관련 테스트 2개 추가를 요청함(테스트 16개 통과). .gitignore와 대조해 정리 파일 저장 폴더가 data/processed로 되어 있어 GitHub에 올라갈 수 있는 것을 발견 → 팀 규칙인 data/clean으로 변경함. collect.py가 실제 수집 데이터를 data/sample에 저장하고 있어서, data/raw로 바꾸고 샘플은 clean.py --make-sample로 3일치만 만들자고 팀에 제안할 예정
